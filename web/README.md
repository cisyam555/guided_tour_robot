# 循展 · 导览讲解工作台

为 guided_tour_robot 制作的独立只读网页。采用温馨的展馆导览手册风格：封面插画与前置实时画面并排，设备数据收成随行状态栏，下方用章节目录和讲解手记组成双页阅读布局。奶油白、鼠尾草绿和纸张杏色配色，与 visitor_wayfinding_robot 的任务监控面板区分。包含导览总览、讲解内容库、设备监测和运行日志，适配手机。

## 使用

机器人上的访问地址：`http://192.168.21.19:8767/`。原有 8765 网页保持独立。

在机器人项目目录运行：

```bash
bash web/start_monitor.sh --port 8767
```

本地仅预览路线和讲解配置，不连接硬件：

```bash
python3 web/monitor.py --preview --bind 127.0.0.1 --port 8767
```

浏览器访问 `http://127.0.0.1:8767/`。请通过服务访问，不直接双击 HTML 文件。

## 内容与数据

- 路线、迎宾话术、唤醒词、逐站讲解直接读取 `src/learn1_d/learn1_d/tour.json`，约每 15 秒刷新。
- 点击展点或前后箭头仅浏览讲解稿，不代表机器人的真实导览进度。
- 正常模式约每 2 秒更新服务主机 CPU、温度和内存；约每 5 秒发现 ROS 图和读取底盘电池。充电状态采用底盘明确的 `isCharging` 字段。
- 相机订阅现有头部 RGB / 深度话题，网页约 3 FPS；无新帧时显示等待，不展示过期画面。
- 日志包括监测连接事件及相关 ROS 警告，可筛选、暂停显示、导出。机器人终端中的全部导览输出尚未接入。
- 定位、任务进度和当前运行地图尚未接入，会明确显示未知。配置阈值不是实机安全许可。

## 运行边界

仅增加独立监测服务，不修改原机器人程序，不启动导览、导航、播报或底盘，不发布运动指令，不调用机器人控制服务。所有写入 HTTP 方法返回 405。只提供固定页面和只读 API，不提供目录或源文件下载。默认绑定局域网地址；供可信局域网使用。

机器人环境依赖 ROS 2 Jazzy、现有 xos 工作区、Python 3、psutil、numpy、opencv；启动脚本加载现有环境，不安装依赖。

验证命令：

```bash
cd web
python3 -m unittest test_monitor -v
node --check app.js
```
